# VeloTab
**Creado por ItzUsman** | [itzusman.netlify.app](https://itzusman.netlify.app)

VeloTab es una suite integral para la gestión de servidores de Minecraft, diseñada para ofrecer seguridad, estética y control total sobre la experiencia del jugador.

## 🚀 Características Principales
*   **JAR Universal**: Un único archivo compatible con Paper, Spigot, Purpur y Velocity.
*   **Seguridad de Comandos**: Filtrado inteligente de Tab-Complete basado estrictamente en permisos de LuckPerms. Oculta versiones con prefijo y versiones cortas automáticamente.
*   **TabList Dinámico**: Personaliza el Header y Footer con soporte para MiniMessage (RGB/Gradientes) y PlaceholderAPI.
*   **Scoreboard Profesional**: Sistema de Scoreboard integrado, animado y libre de parpadeos.
*   **Orden de Rangos (Sorting)**: Organiza a los jugadores en el TabList según su rango de LuckPerms.
*   **Chat Interactivo**: Formateo de chat que conserva eventos de hover y click (Adventure API).
*   **Multi-Idioma**: Soporte nativo para Español e Inglés, configurable y recargable en caliente.

## 🛠️ Instalación
1. Descarga el archivo `VeloTab.jar` desde la sección de Releases.
2. Coloca el archivo en la carpeta `plugins` de tu servidor (Paper/Spigot) o Proxy (Velocity).
3. Reinicia el servidor para generar la configuración inicial.
4. ¡Configura a tu gusto en `config.yml` y los archivos de la carpeta `lang/`!

## 💻 Comandos
*   `/velotab info`: Muestra información del autor y estado del plugin.
*   `/velotab reload`: Recarga la configuración y los archivos de idioma al instante.
